# Crypto Vault - AstrBot 跨群图库图片混淆插件

一个基于 AstrBot 和 aiocqhttp 的高级图片加密与解密插件。
该插件用于降低图片内容直接出现在群聊中的风险。它通过可逆像素混淆处理图片，并可将处理后的图片统一转发到指定的“安全群聊”；用户通过机器人私聊接收还原结果。

当前版本：`1.0`  
作者：[@MeSun424](https://github.com/MeSun424)

## 核心特性

跨群统一存储：将各个群聊中触发加密的图片，以合并转发的形式统一发送到配置好的“安全图库群”。

私聊解密投递：用户在群内引用混淆后的图片或合并转发记录时，机器人会通过私聊发送还原结果，不在主群直接展示原图。

多种图片提取方式：支持直接图片、引用消息、合并转发、JSON/XML 卡片和部分嵌套合并转发，并会尝试通过 OneBot `get_image` 补取缺失的图片 URL。

像素混淆算法：内置基于 Gilbert 2D 空间填充曲线的可逆像素置换算法。

## 环境要求

AstrBot 机器人框架

协议端：仅支持 aiocqhttp (OneBot v11)。因本插件重度依赖底层 API 发送群聊和私聊的“合并转发”消息，暂不支持其他不支持该特性的协议端。

## 安装方法

下载本插件的 .zip 压缩包（注意：压缩包内应直接包含一个名为 astrbot_plugin_crypto_vault 的文件夹，文件夹内才是代码文件）。

进入 AstrBot 的网页控制台。

导航到 插件管理 -> 上传插件，选择你的 .zip 文件进行安装。

重启 AstrBot 即可加载插件。

## 配置说明

安装并重启后，请务必在 AstrBot 网页控制台完成基础配置，否则插件无法正常工作。

在控制台左侧菜单找到本插件的配置页面。

接收加密合并转发图片的群聊QQ号列表 (target_group_ids)：

填入你准备作为“安全图库”的群号（纯数字）。

可填写多个，有人触发 `/加密2` 时，机器人会往这些群里同步发送。

## 使用指南

### 1. 在当前会话返回混淆图片

指令：/加密 [图片] 或 /混淆 [图片]

用法：

直接在消息中带上图片：/加密 [图片1] [图片2]

引用含有图片的消息并回复：/加密

效果：机器人处理图片后，将结果发回当前会话。超过 6 张图片时，以每个节点最多 6 张图片的合并转发形式返回。节点会显示触发用户的昵称和 QQ 头像。

### 2. 转发到安全图库

指令：/加密2 [图片] 或 /混淆2 [图片]

效果：机器人处理图片后，以合并转发形式发送到配置的安全群聊。转发节点使用触发用户的 QQ 号和当前昵称，因此显示该用户的 QQ 头像和昵称。

### 3. 解密图片

指令：/解密 [图片] 或 /解析 [图片]

用法：

引用加密过的图片并回复：/解密

(推荐) 引用机器人发送的“加密图片合并转发记录”并回复：/解密

效果：机器人会自动将引用的合并转发记录中的所有加密图片提取出来进行解密，并将结果通过私聊合并转发发给你。

注意：

- 使用 `/解密` 前，请确保用户已经添加机器人为好友，或者机器人拥有在该群内发起临时会话的权限。
- 如果 QQ 已将记录中的图片替换为“[图片]已过期”，且 OneBot 不再提供文件或下载地址，插件无法恢复原图，只会跳过并提示。
- 本插件提供的是可逆图片混淆，不是密码学加密。

### 4. 分享贡献排行榜

指令：

- `/涩图榜`：查看累计通过 `/加密2` 成功分享的图片总榜。
- `/涩图月榜`：查看当月成功分享的图片月榜。

只有至少成功发送到一个安全群聊的 `/加密2` 图片才会计入贡献，每张图片只计算一次，不按安全群聊数量倍增。普通 `/加密` 不参与统计。

插件会实时记录贡献。首次查询排行榜时，还会分页读取好友私聊历史中机器人发送的“处理完毕！已将 n 张加密图片转发至...”回执，用于回填已有总榜和当月数据。每位好友最多向前扫描 100000 条私聊消息；临时会话、已被 QQ 清理或 NapCat 本地数据库无法提供的旧记录仍无法回填。

排行榜会根据实际上榜人数动态调整画布高度，最多完整显示前 10 名。

## 隐私与数据说明

- 插件不会在代码或仓库中预置 QQ 号、邮箱、访问令牌或本机路径。
- `target_group_ids` 仅从 AstrBot 配置读取，用于发送到你指定的群聊；请勿将真实群号提交到公开仓库。
- 贡献榜数据保存在 AstrBot 的插件数据目录中，包含运行中收集的 QQ 标识和昵称，不会随插件源码发布。
- 排行榜页面会根据 QQ 号请求对应头像；如使用远程 HTML 渲染服务，请确认其隐私策略。
