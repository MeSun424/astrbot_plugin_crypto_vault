# Crypto Vault

AstrBot 的 QQ 图片混淆插件。它可以把图片处理后发回当前聊天，也可以集中转发到指定的图库群；需要查看原图时，引用处理后的图片即可让机器人私聊发送还原结果。

当前版本：`1.0`  
作者：[@MeSun424](https://github.com/MeSun424)

## 功能

- 将图片可逆地打乱像素，避免原图直接出现在群聊中。
- 支持直接发送图片、引用消息、合并转发，以及部分卡片消息中的图片。
- 可把处理后的图片转发到一个或多个图库群。
- 支持累计贡献榜和当月贡献榜。

这里的“加密”是图片混淆，不是密码学加密。不要把它当作保护机密文件的工具。

## 使用条件

- AstrBot
- `aiocqhttp` / OneBot v11
- 机器人需要能够发送群聊和私聊合并转发消息

其他协议端是否可用，取决于它是否提供这些接口。

## 安装

1. 下载本仓库，或下载包含 `astrbot_plugin_crypto_vault` 文件夹的 ZIP 压缩包。
2. 在 AstrBot 网页控制台打开“插件管理”，上传 ZIP 文件。
3. 重启 AstrBot。

## 配置

安装后，在插件配置页面填写 `target_group_ids`。

这是接收 `/加密2` 结果的图库群号列表，只填写纯数字群号。例如：

```json
{
  "vault_settings": {
    "target_group_ids": [123456789]
  }
}
```

可以填写多个群号。未配置图库群时，`/加密2` 不会产生有效结果。

## 命令

### 在当前会话处理图片

`/加密` 或 `/混淆`

直接在命令后附上图片，或引用一条包含图片的消息后发送命令。处理结果会发回当前会话。

### 转发到图库群

`/加密2` 或 `/混淆2`

处理结果会发送到配置的图库群，并在当前会话返回处理结果。每张图片只要成功发送到至少一个图库群，就会计入贡献榜。

### 还原图片

`/解密` 或 `/解析`

引用处理后的图片或机器人发送的合并转发记录后发送命令。机器人会把还原结果通过私聊合并转发给你。

使用前请先添加机器人为好友，或确认机器人可以在当前群发起临时会话。

如果 QQ 已经把记录中的图片标记为“[图片]已过期”，且协议端无法提供原文件，插件无法还原这张图片。

### 查看贡献榜

- `/涩图榜`：累计榜
- `/涩图月榜`：当月榜

普通 `/加密` 不计入排行榜。排行榜最多显示前 10 名。

## 数据说明

贡献榜会保存在 AstrBot 的插件数据目录中，记录参与贡献的 QQ 标识和昵称。图库群号由管理员在 AstrBot 配置中填写，不包含在本仓库的代码里。

排行榜显示头像时会按 QQ 号请求 QQ 头像服务；如果部署环境使用了远程网页渲染服务，请一并考虑该服务的隐私政策。
